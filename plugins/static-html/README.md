# Static HTML

The local `static-html` emitter publishes standalone HTML files from `content/` at their original paths. For example, `content/software/radicle/identity-lookup-map.html` becomes `/software/radicle/identity-lookup-map.html`. The files are served unchanged, without Quartz's page layout.

The plugin respects Quartz's `ignorePatterns` and Git ignore rules. Like other assets, these files are public even if they are not linked from a published note. Keep any referenced CSS, JavaScript, and other assets at URLs that work from the published location.

Do not use an HTML path already generated by a Quartz page (for example, both `content/example.md` and `content/example.html`). The build reports a conflict rather than overwriting the generated page. Likewise, `content/static/example.html` conflicts with `quartz/static/example.html`.
